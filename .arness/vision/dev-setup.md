# Development Environment Setup

Generated by `/arn-spark-dev-setup` on 2026-04-16.

## Environment Overview

**Type:** Native

**Rationale:** The Wharfinger Courier is a single-user Python CLI with no services, no database, and no GUI. A native venv setup is the lowest-friction option — one script, four pip packages, and the tool is running.

**Supported platforms:** Linux / WSL

## Prerequisites

### Linux / WSL

- **Python 3.10+** — the runtime. Check with `python3 --version`. Install via your distro's package manager if needed:

  ```bash
  # Ubuntu / Debian
  sudo apt install python3 python3-venv python3-pip

  # Arch
  sudo pacman -S python
  ```

- **git** — for cloning the repository. Usually pre-installed; `git --version` to verify.

- **Optional: pyenv** — for Python version management. The project includes a `.python-version` file pinning `3.12`. See https://github.com/pyenv/pyenv for install instructions.

## Setup Instructions

### Quick Start

```bash
git clone <repo-url>
cd wharfinger-courier-arness
bash scripts/setup.sh
source .venv/bin/activate
courier --help
```

### Detailed Setup

#### 1. Clone the repository

```bash
git clone <repo-url>
cd wharfinger-courier-arness
```

#### 2. Run the setup script

```bash
bash scripts/setup.sh
```

The setup script will:
- Verify Python 3.10+ is available
- Create `.venv/` if it does not already exist
- Install the package in editable mode with test dependencies (`pip install -e ".[test]"`)
- Print the activation command on success

The script is idempotent — running it again on an existing venv reinstalls without recreating it.

#### 3. Activate the venv

```bash
source .venv/bin/activate
```

Your prompt will show `(.venv)` when active. You need to activate the venv in each new shell session.

#### 4. Configure the tool

Copy the example config and fill in your values:

```bash
mkdir -p ~/.config/courier
cp config.example.toml ~/.config/courier/config.toml
# edit ~/.config/courier/config.toml with your Pinboard RSS feed URL and output directory
```

Get your Pinboard RSS secret from https://pinboard.in/settings/password. The feed URL format is:
```
https://feeds.pinboard.in/rss/secret:YOUR_SECRET/u:YOUR_USERNAME/toread/
```

`config.toml` is gitignored — never commit your feed URL secret.

#### 5. Verify the setup

```bash
pytest tests/ -v         # should show 3 passing smoke tests
courier --help           # should show the CLI help
ruff check courier/ tests/  # should show no issues
```

## Troubleshooting

### `python3` not found or version too old

**Symptom:** `setup.sh` exits with "Python 3.10 or newer is required"

**Cause:** System Python is absent or below 3.10.

**Fix:**
```bash
# Ubuntu 22.04+
sudo apt install python3.12 python3.12-venv

# Or use pyenv
pyenv install 3.12
pyenv local 3.12
```

### `courier: command not found` after setup

**Symptom:** Typing `courier` after setup gives "command not found".

**Cause:** The venv is not activated in the current shell.

**Fix:**
```bash
source .venv/bin/activate
courier --help
```

### Import errors on `import readability` or `import trafilatura`

**Symptom:** `ModuleNotFoundError` when running the tool or tests.

**Cause:** The package was not installed into the active venv, or a different Python/venv is active.

**Fix:**
```bash
pip install -e ".[test]"
```

### Feed URL returns 401 or empty feed

**Symptom:** Tool reports no bookmarks or an HTTP error fetching the feed.

**Cause:** The RSS secret token in `config.toml` is incorrect or the URL format is wrong.

**Fix:** Verify the feed URL format and secret at https://pinboard.in/settings/password. The URL must include the secret token segment (`secret:…`).
