# Image localisation implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Download article images during the pipeline and rewrite `<img src>` to local relative paths so ebook-convert embeds them in the AZW3.

**Architecture:** A new `courier/images.py` module exposes `localise_article_images(content, images_dir, article_url) -> str`. It parses `<img>` tags from extracted HTML, downloads each image URL, checks dimensions with Pillow, saves to `images_dir`, and rewrites `src` to `images/filename`. The orchestrator calls it after extraction; the compiler and template are unchanged.

**Tech Stack:** Python stdlib (`hashlib`, `io`, `pathlib`, `urllib.parse`), `lxml` (already a dependency), `requests` (already a dependency), `Pillow` (new dependency).

- [ ] **Step 3: Create `courier/images.py` with the minimal implementation**

  The module needs these imports: `hashlib`, `io`, `logging`, `pathlib.Path`, `urllib.parse.urljoin`, `urllib.parse.urlparse`, `requests`, `lxml.html.fromstring` (alias `html_fromstring`), `lxml.html.tostring` (alias `html_tostring`), `PIL.Image`, `PIL.UnidentifiedImageError`.

  Implement `localise_article_images(content, images_dir, article_url) -> str`:

  - Wrap `content` in `<div>…</div>` and parse with `html_fromstring`.
  - Find all `<img>` elements with `.xpath(".//img")`.
  - For each img:
    - Get `src = img.get("src", "")`. If empty or not starting with `http://` or `https://`, skip (leave tag unchanged).
    - Resolve with `urljoin(article_url, src)` to handle relative URLs (for absolute URLs this is a no-op).
    - Compute `ext = _ext_from_url(absolute_url)` (helper below).
    - Compute `filename = hashlib.sha256(absolute_url.encode()).hexdigest()[:16] + ext`.
    - Compute `local_path = images_dir / filename`.
    - If `local_path` does not exist: call `saved_name = _download_and_save(img, absolute_url, local_path, images_dir)`. If `saved_name` is `None`, `continue` (tag already replaced by helper). Otherwise use `saved_name` as the final filename for the src rewrite.
    - If `local_path` does exist (cache hit): `saved_name = filename` (no download needed).
    - Set `img.attrib["src"] = f"images/{saved_name}"`.
    - Remove `srcset` from `img.attrib` if present.
  - Serialise back: return `(tree.text or "") + "".join(html_tostring(c, method="xml", encoding="unicode") for c in tree)`.

  Implement `_ext_from_url(url: str) -> str`:
  - Parse the URL path with `urlparse(url).path`.
  - Take the suffix with `Path(path).suffix.lower()`.
  - Return it if it is in `{".jpg", ".jpeg", ".png", ".gif", ".webp", ".svg"}`, else return `""`.

  Implement `_download_and_save(img, url, local_path, images_dir) -> str | None`:
  - Download with `requests.get(url, timeout=30)` wrapped in try/except.
  - On any exception: `logger.warning(...)`, call `_replace_img_with_text(img, "[Image]")`, return `None`.
  - Call `response.raise_for_status()` (also in try/except).
  - `image_bytes = response.content`.
  - If `local_path.suffix == ""`: derive ext from `response.headers.get("Content-Type", "")` using a dict `{"image/jpeg": ".jpg", "image/png": ".png", "image/gif": ".gif", "image/webp": ".webp"}`. Update `local_path` with the new suffix.
  - Open with `Image.open(io.BytesIO(image_bytes))` in try/except `(UnidentifiedImageError, Exception)`. On failure: `logger.warning(...)`, `_replace_img_with_text(img, "[Image]")`, return `None`.
  - If `img.width < 10 or img.height < 10`: `logger.debug(...)`, `_remove_img(img)`, return `None`. (Use `pil_img.size` — `width, height = pil_img.size`.)
  - `images_dir.mkdir(parents=True, exist_ok=True)`.
  - `local_path.write_bytes(image_bytes)`.
  - Return `local_path.name`.

  Implement `_replace_img_with_text(img, text: str) -> None`:
  - Get `parent = img.getparent()`. If `None`, return.
  - `tail = img.tail or ""`; `replacement = text + tail`.
  - Find `idx = list(parent).index(img)`, then `parent.remove(img)`.
  - If `idx == 0`: `parent.text = (parent.text or "") + replacement`.
  - Else: `prev = parent[idx - 1]`; `prev.tail = (prev.tail or "") + replacement`.

  Implement `_remove_img(img) -> None`:
  - Same as `_replace_img_with_text` but `replacement = tail` (no added text).
